# Takeoff Source Reference

The `Takeoffs/` folder contains one source artifact. It is preserved unchanged and is used only as read-only visual context for the Takeoff training module.

| File | Type | What it demonstrates | How it should be used in Academy training |
| --- | --- | --- | --- |
| `Takeoffs/20260824110900240.pdf` | Completed takeoff example / PDF | A manual, color-coded takeoff sheet and grid-based tally presentation. The file is the authoritative visual reference for the physical takeoff process. | Link from the Takeoff lessons as a read-only example. Use it to discuss the sequence `identify -> highlight -> count -> cross off -> tally`; do not alter the source or replace it with a generic drawing. |

## Evidence Boundaries

- The PDF is not used to assert color-to-product assignments or part-number mappings that cannot be read confidently from the source.
- No new color assignments are published. Any unclear color relationship requires clarification from Ban-Koe before it is added to training.
- The existing Academy product data remains the source for verified product identities.
- The existing Takeoff simulator remains the practice mechanism. An interactive practice drawing is a future feature, not fabricated here.

## CONFIRMED BAN-KOE TAKEOFF COLOR SYSTEM

The following mappings are user-confirmed Ban-Koe takeoff procedures provided separately from the original PDF. They are not being attributed to the PDF, and they do not assign Edwards part numbers.

| Color | Product types |
| --- | --- |
| DARK BLUE | FACP; FAA |
| RED | Smokes |
| LIGHT BLUE | R of R Heats; Fixed Heats |
| ORANGE | Duct Smokes; Test Stations; Wall Strobes; Ceiling Strobes |
| YELLOW | Wall Horn/Strobes; Wall Speaker/Strobes; Ceiling Horn/Strobes; Ceiling Speaker/Strobes; Weatherproof Devices |
| GREEN | Pulls |
| PINK | Dampers; Waterflow; Door Holders; CR's; CT-1; CT-2; Tamper |

Color organizes takeoff product types visually. Part-number mappings require separate verification and are intentionally not included here.
